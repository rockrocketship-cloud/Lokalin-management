# audio/

Klip pengumuman opsional untuk `suara-panggilan.js`. Nama file:
`panggilan-<slug-nama-ruang>.wav`, mis.:

- `panggilan-meeting-room-lantai-1.wav`
- `panggilan-meeting-room-lantai-2.wav`

Selama folder ini kosong, iPad memakai suara bawaan perangkat (Web Speech
API, id-ID) — pelafalan Indonesia sudah benar dan tidak perlu setup apa pun.
Klip di sini hanya perlu kalau kamu ingin suara tertentu, misalnya suara
sendiri hasil kloning dengan Pocket TTS.
